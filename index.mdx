## Get Running in Seconds

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/DhanikaJ/Santa-Run.git
    cd Santa-Run
    ```
  </Step>
  <Step title="Open the game">
    Open `index.html` directly in your browser — no server required.
    ```bash
    open index.html   # macOS
    start index.html  # Windows
    xdg-open index.html  # Linux
    ```
  </Step>
  <Step title="Start playing">
    Press **Enter** to start Santa running, then press **Space** to jump over incoming flame obstacles. Survive as long as possible to rack up the highest score.
  </Step>
</Steps>

<Note>
  Santa Run runs entirely in the browser with no server-side dependencies. All assets — sprites, sounds, and background — are bundled in the repository.
</Note>
